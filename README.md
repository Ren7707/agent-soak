# agent-soak

AI-ready universal soak testing for CLI tools and web agents.

This is an independent personal project. It uses a manifest plus a small
platform adapter to provide safe preflight checks, repeatable scenarios,
run-scoped test data, cleanup recovery, supervised Playwright runs, and
structured reports.

## Status

The MVP is under development. See the [design](docs/design/2026-09-03-universal-soak-framework.md).

## Privacy Boundary

The repository contains only public framework code, a local demo platform,
fictional data, and test fixtures. Do not add credentials, private URLs,
customer data, internal API contracts, screenshots, traces, or production
reports.
